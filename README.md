# TypePy-Prelude

> Репозиторий для сборки Type Py Prelude — Python-примитивов, вдохновлённых Rust.

## Что это

Базовая архитектура для Python-проекта: строгая типизация, явный `Option`/`Result` вместо `None` и исключений, неизменяемые структуры, функциональная композиция вместо цепочек мутирующих методов. Замедляет написание кода на старте, зато даёт язык, на котором можно делать проекты серьёзнее скрипта на 200 строк — производительность у Python при этом всё равно остаётся его слабым местом, это архитектура не лечит.

Компоненты:

- **Типизация в strict-режиме** — `pyright` и `mypy` со `strict = True`, дженерики через синтаксис Python 3.12 (`class Some[T]`, `def map[T, U](...)`), `Any` не используется по умолчанию.
- **`Option[T]`** — `Some[T] | None` с обработкой через `match`, вместо `None` и `AttributeError` в неожиданном месте.
- **`OptionBox`** — цепочки `.map().and_then().unwrap_or(...)` поверх `Option`, чтобы не городить вложенные `if`.
- **`Result[T, E]`** (пакет `result`) — `Ok`/`Err` вместо исключений без явного контракта в сигнатуре функции.
- **`pyrsistent`** — неизменяемые коллекции.
- **`toolz`** — `pipe`/`compose` для функциональной композиции.
- **`returns.context.RequiresContext`** — DI без глобальных переменных.

Сам репозиторий — не приложение, а зависимость (workspace-член через `uv`), которую подключают к другим проектам. `new-project.ps1` создаёт новый проект через `uv`, подключает TypePy-Prelude, ставит `result`/`toolz`/`returns`/`pyrsistent`, настраивает `pyright`/`mypy` в strict, `ruff` и pre-commit-хуки — так что каркас появляется сразу, а не собирается руками в каждом новом проекте.

## Быстрый старт

1. Скачай `new-project.ps1` со страницы [Releases](../../releases) этого репозитория.
2. Положи файл туда, где удобно:
   - в папку, где будешь создавать проекты, и запускай оттуда;
   - или в отдельную папку для скриптов (например `C:\Users\Honami\Scripts\`) и обращайся к нему по полному пути.
3. Запусти PowerShell:

   ```powershell
   powershell -ExecutionPolicy Bypass -File "C:\Users\Honami\Scripts\new-project.ps1" -Name myproject
   ```

   - `C:\Users\Honami\Scripts\new-project.ps1` — путь до скачанного файла;
   - `myproject` — имя нового проекта.

Скрипт создаст папку `myproject`, склонирует TypePy-Prelude как editable-зависимость, поставит `result`, `toolz`, `returns`, `pyrsistent`, настроит strict-типизацию и git hooks.
